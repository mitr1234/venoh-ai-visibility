# Venoh AI Visibility

Check whether AI assistants recommend your business when buyers ask, and who they name instead.

Remote MCP server: `https://mcp.venoh.com/mcp` (no sign-in, read-only).

## Tools

- `check_ai_visibility` - free check of one website: asks AI search 5 buyer questions and shows whether your business is named, and which rivals are named instead.
- `find_buyer_questions` - the questions your buyers ask AI about your category.
- `get_venoh_plans` - Venoh plans and prices.

## Install

Gemini CLI:

```bash
gemini extensions install https://github.com/mitr1234/venoh-ai-visibility
```

Claude, ChatGPT, Cursor and other MCP clients: add `https://mcp.venoh.com/mcp` as a remote (Streamable HTTP) server.

Official MCP Registry name: `com.venoh/ai-visibility`
